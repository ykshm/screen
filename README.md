# 青の時間

チルな音楽を流しながら、ブルーモーメント（夕暮れと夜のあいだ）の写真をスクリーンセーバーのように眺めるための、1枚もののWebページです。
吉村和敏の写真集の空気感——ヨーロッパの村、プリンス・エドワード島、雪の村と灯り、田園と空——を目指しています。

依存なし、`index.html` だけで動きます。写真はその場で取ってきて眺めるだけで、このリポジトリにもサーバーにも保存しません。

## 使いかた

1. ページを開く（GitHub Pages か、`index.html` をブラウザで直接開く）
2. <kbd>F</kbd> で全画面にする
3. マウスを動かすと右上に「設定」が出る。テーマ（複数可）、切り替え間隔、青の深さを好みに合わせる
4. 音楽は「曲を選ぶ」から手元のアルバムを選ぶ。選んだ順に繰り返し再生される
5. 自分の写真を眺めたいときは「写真を選ぶ」。端末の中だけで使われ、どこにも送られない

設定はURLの `#` 以降に残るので、ブックマークしておけば次も同じ設定で開けます。

### 写真の出どころ

| 出どころ | 必要なもの | 特徴 |
| --- | --- | --- |
| Wikimedia Commons | なし | 当たり外れはあるが良い写真もある。CC系ライセンスなので撮影者を表示 |
| Unsplash | 無料の Access Key | 写真の質が高い。鍵はURLにだけ残り、コードには入れない |
| 自分のフォルダ | なし | 端末内で完結 |

Unsplash の鍵は [unsplash.com/developers](https://unsplash.com/developers) でアプリを1つ作ると発行されます。

### キー

| キー | はたらき |
| --- | --- |
| <kbd>Space</kbd> | 止める・進める |
| <kbd>→</kbd> | 次の一枚 |
| <kbd>F</kbd> | 全画面 |
| <kbd>C</kbd> | キャプションの表示・非表示 |
| <kbd>S</kbd> | 設定を開く・閉じる |
| <kbd>Esc</kbd> | 設定を閉じる |

### スマホ・タブレットで

ブラウザの「ホーム画面に追加」をすると、アドレスバーなしの全画面で起動します（`manifest.json` で `display: fullscreen` を指定）。

## 公開する（GitHub Pages）

リポジトリの Settings → Pages → Build and deployment で、Source を **Deploy from a branch**、Branch を **main** の **/ (root)** にして保存すると、しばらくして `https://<ユーザー名>.github.io/screen/` で開けるようになります。

## しくみ

- 2枚のスライドを4秒のクロスフェードで切り替え、ケン・バーンズ効果でゆっくり動かす
- 「青の深さ」は青系グラデーションを `mix-blend-mode: multiply` で重ね、写真ごとの色味をそろえる
- 薄いフィルムグレインとビネット、左下に写真集風キャプション、右下に明朝の時計
- 在庫が6枚を切ると、テーマごとの検索語 `THEMES` を順に回して補充する。Commons は横長で幅1600px以上の写真だけ採用
- 操作しないと3.5秒でカーソルと操作ボタンが消える。`prefers-reduced-motion` にも対応

## 注意

- Unsplash の Access Key をコードやコミットに入れないでください
- Commons の写真は CC 系ライセンスなので、キャプションの撮影者・ライセンス表示は消さないでください
- Unsplash は表示時に撮影者名を出す規約です。キャプションは既定で出しています
